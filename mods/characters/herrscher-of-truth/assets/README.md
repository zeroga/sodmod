# Herrscher of Truth asset tracking

No original Honkai Impact 3rd/HoYoverse models, textures, sounds, animations or proprietary Mod resources are included here.

- `source/`: local originals; ignored by Git (license audit required).
- `private/`: local evaluation assets; ignored by Git.
- `runtime/`: generated runtime files placed at the ZIP's Mod root; ignored by Git.
- `public/`: if used in the future, only assets with documented permission for redistribution.

The two initial forms are **Extremum** and **Continuation**. The initial visual transition is a direct model swap with a short optional masking effect; mechanical assembly animation is explicitly deferred. No model loader implementation has yet been validated in the actual game.
