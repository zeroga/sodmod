# 真理之律者（Herrscher of Truth）— 角色能力设计

> 项目：《梦之形》（Shape of Dreams）角色 Mod  
> 文档版本：V0.3（阶段性设计稿）  
> 最后更新：2026-10-29  
> **已确认**：用户明确决定的设计；**设计建议**：可讨论但未定案；**待技术验证**：需 API 原型或联机实测。  
> 本文档作为角色能力设计的项目记录；禁止把猜测性数值、推荐方案或未经验证的接口行为当作已定规格。

## 1. 总体定位与设计边界

- **已确认：双形态是角色的核心设计。**极值形态为布洛妮娅本体，延拓形态为布洛妮娅与重装小兔合体的完整机甲，两者拥有不同的基础战斗体系。
- **已确认：专属终极记忆「形态切换」负责变身；身份记忆「重装小兔」负责能量驱动的协同攻击。**两项记忆均能单独发挥作用，组合使用提高效率。
- **已确认：机甲合体期间不存在独立支援的重装小兔。**机甲形态的光束、飞弹与浮游炮由形态自身提供，不以装备身份记忆为前提。
- **已确认：两个普通旅行者记忆是可替换的构筑选项，且同一普通记忆随形态改变具体技能效果。**
- 初版美术：直接切换布洛妮娅与完整机甲两套独立 3D 模型，不制作重装小兔拆分／组装变形动画。
- 依照《梦之形》的原生记忆、攻击／闪避判定及精粹构筑进行开发，而不是复刻《崩坏3》的独立 SP／按键系统。

> 「双形态是角色核心」不等于更换掉专属终极记忆后仍免费保留变身。更换记忆后能否进入机甲由该记忆是否仍装备决定。

## 2. 身份记忆：「重装小兔」

### 2.1 三种独立武装能量（已确认）

三种武装以战斗行为积累能量，重装小兔自动发起攻击并消耗对应能量，不再采用原作依次永久解锁武装的机制。

| 武装 | 能量获取来源 | 资源消耗／攻击 |
|---|---|---|
| 激光 | 角色普通攻击 | 重装小兔消耗激光能量自动发射激光 |
| 导弹 | 角色闪避 | 重装小兔消耗导弹能量自动发射导弹 |
| 浮游炮 | 角色造成寒冷伤害 | 重装小兔消耗浮游炮能量自动攻击 |

- 三条能量槽各自积累和消耗，无前置顺序，允许并行。
- **没有无条件自动攻击**：能量不足时对应武装不可开火；三种能量都不足时，重装小兔停止攻击。
- 不额外设置无条件的自动能量恢复。攻击必须以相应能量为代价。
- 能量获取来源应使用游戏真正的普通攻击、闪避及寒冷伤害事件，不应仅识别专门为重装小兔创建的伪标签。

### 2.2 与终极记忆的联动（已确认）

- 重装小兔武装攻击除了造成伤害，还**专门为「形态切换」终极记忆额外充能**。
- **重装小兔攻击不能为其他终极记忆充能**，包括不得通过通用伤害充能间接充能。
- 玩家自己的正常战斗伤害继续按照游戏原生规则获得终极记忆充能。
- 身份记忆不依赖变身技能：没有装备「形态切换」时，仍可以按三种能量机制独立自动作战，但不享有终极充能联动。

### 2.3 与合体的资源关系（已确认）

1. 极值形态：重装小兔独立协同作战，依靠玩家行为充能，自动消耗能量。
2. **进入延拓形态：立即清空重装小兔三条武装能量。**
3. 延拓形态：布洛妮娅与重装小兔合体，**没有独立的重装小兔攻击或其专属终极额外充能**；机甲自行使用各项武装。
4. 解除合体：恢复独立的重装小兔，默认三条武装能量为零。
5. **可通过角色升级获得「解除变身时恢复一定重装小兔武装能量」的效果。**具体恢复量与升级形式待定。

> 是否在延拓形态期间积累身份记忆能量，当前方向为停止独立武装运作、进场清零，暂不额外创造储能机制；如需形态下的攻击事件继续给身份记忆充能，须另行讨论。

### 2.4 待设计

普攻「发动／命中」计能量规则、闪避是否需实际成功、寒冷伤害按伤害量还是命中计算、每次增减量、上限、攻击频率、攻击归属及防止召唤物寒冷伤害引发自身充能的循环；死亡／换房间的资源处理。

## 3. 专属终极记忆：「形态切换」

### 3.1 形态与终极充能（已确认）

- 专属终极记忆驱动极值形态与完整机甲延拓形态之间的转换。
- 未装备身份记忆时仍可按原生战斗途径使「形态切换」充能并变身；装备「重装小兔」则额外获得其独占的攻击充能。
- **无强化时，延拓形态有持续时间，到期自动解除。**
- **变身属于与重装小兔合体，不再保留重装小兔独立支援。**

待定：终极充能和变身冷却数值；延拓基础持续时间；按终极技能键主动解除是否需要独立规则；期间能否充能；终结攻击动作和伤害形式。

### 3.2 角色升级（已确定方向，数值与具体承载系统待定）

| 升级方向 | 效果 | 关系 |
|---|---|---|
| 能量回收 | 解除变身时恢复部分重装小兔三武装能量 | 独立 |
| 主动终结攻击 | 玩家主动解除变身时发动终结攻击 | 独立，可与下两项任一搭配 |
| 到期自动终结 | 变身持续时间结束时自动发动终结攻击 | **与无限延拓互斥** |
| 无限延拓 | 变身不再受持续时间限制 | **与到期自动终结互斥** |

- 自动终结与无限延拓是两条不同升级路线，**不能同时有效**；如游戏原生星座／角色升级不支持硬性互斥，应在 Mod 逻辑中排他，具体装备层面的阻止方式待验证。
- **主动终结攻击与自动终结不是同一项升级**；主动终结可与无限延拓兼容。
- 没有「主动终结攻击」升级时，能否无伤害地主动解除变身：**设计建议**为允许，以避免无限延拓被锁定，具体输入与状态规则待定。
- 自然到期是否触发终结攻击仅由「到期自动终结」升级决定；没有该升级则只解除形态。
- 升级应归属于星座、终极记忆强化还是其他角色成长入口，尚未定案；不直接写死为某个游戏系统。

### 3.3 双记忆独立性

| 装备情况 | 可用功能 |
|---|---|
| 重装小兔＋形态切换 | 充能武装自动作战、双形态、专属额外终极充能 |
| 仅重装小兔 | 充能武装自动作战，没有变身 |
| 仅形态切换 | 双形态和机甲本体火力，没有重装小兔独立协同及额外充能 |
| 均不装备 | 角色基础攻击／闪避与其他记忆构筑 |

## 4. 两种形态的基础战斗

### 4.1 极值形态

- 布洛妮娅本体进行基础普攻和闪避；具体动作、参数仍待设计。
- 装备「重装小兔」时，普通攻击、闪避、实际寒冷伤害为三条武装能量提供对应来源。

### 4.2 延拓形态（已确认）

| 输入／状态 | 效果 |
|---|---|
| 普通攻击 | **持续光束照射**，需要作为真正的机甲普攻参与游戏的攻击规则 |
| 闪避 | **传送，同时发射大量飞弹** |
| 形态持续期间 | **召唤大量浮游炮自动索敌作战** |
| 普通旅行者记忆 | 同一记忆在延拓形态调用不同技能分支，详见第5节 |

- 这些武装是机甲自带能力，**不消耗身份记忆「重装小兔」的三条武装能量**。
- 机甲持续浮游炮群与身份记忆的浮游炮是两套独立来源，不能因名字相同而合并资源或归属。
- 光束普攻的长按规则／攻击速度关系、传送无敌及飞弹细节、浮游炮数量／攻击频率待定。
- 原作延拓形态具有防御与抗打断特色；是否为本 Mod 设置减伤／抗打断及数值**仍是设计建议，未确认**，尤其要与无限延拓路线平衡。

## 5. 两个专属普通旅行者记忆（同一位置的可替换选择）

**已确认：**每个记忆拥有极值形态和延拓形态两套不同效果；作为《梦之形》的普通旅行者记忆，应保留原生记忆系统的冷却、升级及精粹构筑接口。

**设计建议：**同一个记忆的两形态分支共用冷却、等级及精粹，防止通过变身绕开冷却；具体在引擎中能否完整继承、按哪一时点读取形态须验证。

### 5.1 记忆 A：「分支攻击」（偏普攻、闪避触发与瞬时爆发）

#### 极值形态 Q（已确认）

1. 向玩家指定目标位置**瞬移**，保留原作后撤撤离的定位。
2. 瞬移**作为游戏自身真正的闪避事件**参与结算，能够触发适用的闪避相关构筑，而不只是身份记忆的导弹充能。
3. 在**瞬移前的原位置**发生范围**寒冷属性爆炸**。
4. 该爆炸**作为游戏自身真正的普通攻击**参与结算，支持原生普攻命中及其触发效果，不是仅模拟一次「普攻标签」；爆炸造成的寒冷伤害也正常参与游戏寒冷伤害机制。
5. **多目标普攻效果是有意设计的收益：**一次爆炸击中多个敌人，按游戏原生多目标普攻命中／攻击效果规则结算多个目标，不人工压成只触发一次。
6. 玩法取舍：玩家若等敌人包围后再撤离，可得到更多普攻命中／构筑收益，但也承担等待期间更高的风险；提前使用则偏向保命位移。
7. 同时装备身份记忆时，一次 Q 可以经真正闪避、普攻和寒冷伤害途径分别促进导弹、激光和浮游炮充能；**没有身份记忆时仍保持 Q 的原生机制价值**。

> 技术注意：应按「一次普通攻击实例，对多个命中目标按照游戏原生规则分别触发」建模。具体触发倍率、多段技能对普攻事件的映射以实测为准，不承诺可以无限重复触发所有攻击效果。

#### 延拓形态 Q（已确认）

- **失去瞬移能力**，改为向**指定目标位置**发动一次**全武装齐射**。
- 机甲激光、导弹、浮游炮等各自针对目标区域执行一次攻击，主要定位为区域火力爆发。
- 使用机甲自身武装，**不依赖身份记忆「重装小兔」是否装备，也不消耗其能量**。
- 全武装齐射应如何计算伤害、目标数与精粹：待设计。
- **设计建议（尚未确认）：**把延拓 Q 作为普通记忆的技能伤害而非普攻；极值 Q 的普攻特判不自动套用到延拓 Q。

### 5.2 记忆 B：「矢量解析」／「黑洞」（偏远程技能流派）

**构筑目的（已确认）：**极值形态为远程技能输出流派提供被敌人近身时的防反生存能力；延拓形态用黑洞改善远程技能的聚怪与持续命中环境。不是鼓励角色长期站在近战范围承伤。

#### 极值形态：矢量解析／防御反击（已确认）

基础技能是一次**防反窗口**：释放后在有限时间内等待攻击；**防反窗口内第一次符合条件的敌方攻击必须被无效化，不应先扣生命或护盾再补偿**。

| 触发节点 | 未强化 | 拥有「提前反击和护盾」强化 |
|---|---|---|
| 施放技能的瞬间 | 开启防反窗口，不立即造成伤害／护盾 | **立即造成一次反击技能伤害并立即获得护盾**，同时开启防反窗口 |
| 防反窗口内首次成功防御敌方攻击 | 本次攻击**无效化**，随后获得短暂无敌＋反击技能伤害＋一定时间护盾 | 本次攻击**无效化**，随后**只额外获得短暂无敌**，不再次反击／重复发盾 |
| 防反窗口结束但未成功防御 | 不反击、不无敌、不获得护盾 | 已立即取得的反击与护盾有效，但**不获得无敌** |

- 成功防反后，无敌与护盾应在设计规定的顺序中生效；基础版倾向短暂无敌后进入持续护盾阶段，具体结算与叠加策略需原型验证。
- **每次施放只成功防反一次**；连续弹幕或同帧多伤害包不可重复触发多次后续奖励。
- 成功防反只需要符合条件的攻击命中防御窗口，不以生命值实际损失为前提；强化版本预先取得的护盾不应妨碍防反判定。
- 反击属于**技能伤害**，不是普攻；反击伤害属性尚待确定，不自动设为寒冷。
- 目前没有指定的具体数值：防反窗口、无敌时长、护盾值与持续时间、反击范围／倍率均待设计。
- 哪些伤害能触发防反（普通攻击、技能、持续伤害、不可免疫伤害和异常控制），需明确规则并测试。

**该强化的设计取舍：**牺牲「根据成功防反时机发动反击与获得护盾」的反应性，换取主动释放即稳定生效；但短暂无敌始终只能靠成功防反取得。

#### 延拓形态：黑洞（已确认）

- 在指定目标位置产生**持续存在的黑洞**。
- **持续牵引范围内敌人**，并**按间隔造成持续技能伤害**。
- 不视为普通攻击，不自带瞬移；不需要在解除机甲时才释放。
- **牵引是主要价值**：集中目标、减少敌人脱离其他范围技能伤害区域，兼顾生存和持续输出环境。
- 持续伤害的基础输出定位偏辅助；不叠加免费的减抗、易伤等额外增益（当前**设计建议**）。
- **伤害属性尚未确认**：用户希望不绑死寒冷，又担心技能因持续聚怪＋伤害而过泛用。候选方案是非元素技能伤害，并通过较低基础伤害／合理触发间隔平衡；这不是已经确认的属性定义。
- 持续伤害是否高频触发精粹、范围多目标结算的触发效率，须按原生技能效果验证；不宜在初版无依据地无限加频率。

### 5.3 两个普通记忆的构筑分工

| 选择 | 极值形态 | 延拓形态 | 主要构筑 |
|---|---|---|---|
| 分支攻击 | 瞬移闪避＋原地寒冷普攻爆炸（多目标普攻效果） | 定点全武装齐射 | 普攻效果、闪避机制、瞬间爆发 |
| 矢量解析／黑洞 | 防反、无敌、护盾（强化后反击和护盾立即生效） | 持续牵引＋持续技能伤害 | 远程技能输出、防御与区域控制 |

## 6. 技术实施建议（尚未完成原型实测）

以下是**候选接口和实现路径**，不构成「已测得可在游戏版本中直接工作」的承诺。

### 6.1 同一记忆随形态切换行为

- 每次释放同一普通记忆时，根据服务端／权威角色形态执行对应分支，不创建两个独立可绕冷却的 Q。
- 保持同一个记忆对象的冷却、等级和精粹入口；确认原生执行路径是否允许独立伤害实例使用共享精粹信息。
- 需要验证切形态中途、施法中途、精粹额外攻击以及联机同步的状态边界。

### 6.2 极值 Q 原生普攻／闪避复合结算

- 瞬移要真实接入角色闪避事件体系；寒冷爆炸要通过普通攻击类型的有效命中结算，命中不同敌人独立参与原生攻击效果。
- 单次瞬移／爆炸不可因动画／碰撞回调重复触发；多个有效命中目标则不人为合并为一个。
- 如果引擎只允许攻击实例或原生闪避能力发出特定事件，需要通过最小原型验证重用／转发接口；不能使用仅供「重装小兔」识别的自定义标记替代原生效果。

### 6.3 防反：优先使用原生伤害免疫及回调

候选 API／机制：**ProtectedEffect、onDamageNegated、InvulnerableEffect、Actor.GiveShield()、DamageData.BlockWithImmunity()**；另可检查 StatusEffect 的 **DoProtected()/DoInvulnerable()/DoShield()**。这些是下一阶段代码验证的入口，**当前未在本 Mod 原型上验证签名、优先级与联机行为**。

优先采用：防反窗口施加短期原生「免疫伤害」状态 → 第一笔有效敌方攻击在伤害结算前被免疫 → 由成功免疫的回调一次性标记防反成功 → 结束窗口并赋予短暂无敌及相应后续效果。

**不要**等角色扣血后再回血，也不要在无效化第一击后仍让护盾先承伤。强化版需要确保「先发盾、再防反」时仍能捕获合格伤害。

重点验证：
1. 护盾与多重免疫共存时哪个效果先处理，是否会抢走反击回调；某些免疫机制可能只向一个处理者发送回调。
2. 同帧多段伤害、飞行物与持续伤害是否会导致重复防反；回调中切换免疫状态是否存在重入。
3. 是否能够在**第一击**之前阻断伤害及附带控制；不能被免疫的特殊攻击如何处理。
4. 服务端唯一判定防反结果，客户端只表现动画／特效，避免联机重复反击或不同步。
5. 原生 ProtectedEffect 是否同时处理控制状态；若不处理，明确技能需要的是「免伤」还是「攻击整包无效」。

> 对当前设计的技术判断：**值得保留，整体可行方向明确，但不是已证实的低风险功能**。先做无特效原型，验证首次命中免疫、护盾优先级、连续伤害只触发一次，再接入反击和美术。

### 6.4 延拓 Q 黑洞与全武装、角色状态

- 黑洞牵引：需确认敌人位移、霸体与 Boss 控制抗性；黑洞持续伤害／精粹应遵守原版技能命中与触发规则。
- 全武装齐射：武装各一次攻击，明确是若干独立伤害实例还是单次组合技能，并验证与群体伤害精粹交互。
- 合体期间机甲浮游炮群是终极记忆自身能力，不能作为重装小兔独立支援；终极额外充能不在机甲期间由独立小兔产生。
- 实测模型切换、光束普攻、传送落点、浮游炮数量性能、多人权威状态、死亡／复活／换房间／晚加入。
