# 真理之律者（Herrscher of Truth）— 角色能力设计

> 项目：《梦之形》（Shape of Dreams）角色 Mod  
> 文档版本：V0.2（阶段性设计稿）  
> 最后更新：2026-10-29  
> 状态标记：**已确认**＝用户明确决定；**待设计**＝尚未确定；**待技术验证**＝需用原版 API／联机实测。  
> 此文档是角色能力设计的项目记录；不会将尚未讨论的数值、触发细节或实现推测视为定案。

## 1. 设计定位与不可变目标

- **已确认：角色核心是双形态。**
  - **极值形态**：布洛妮娅本体。
  - **延拓形态**：完整机甲，拥有区别于极值形态的独立战斗体系。
- **已确认：专属终极记忆负责双形态切换；身份记忆不负责变身。**
- **已确认：专属身份记忆命名为「重装小兔」，负责自动协同攻击。**
- **已确认：两套专属记忆可以独立使用，同时装备时形成效率联动；不把任何一项记忆的基本功能做成另一项记忆的必选前置。**
- **已确认（美术实现方向）：**初版直接切换布洛妮娅和完整机甲两套独立 3D 模型，不制作重装小兔零件组合机甲动画。
- **设计原则：**兼容《梦之形》的角色、身份记忆、终极记忆、通用记忆及精粹构筑。保留可自由替换的记忆体系，不默认给角色增加独立的变身按键。

> 「双形态是角色核心」指使用专属终极记忆时必须呈现完整双形态玩法；并不代表玩家在主动替换掉该终极记忆之后仍可免费变身。

## 2. 身份记忆：「重装小兔」

### 2.1 核心效果（已确认）

「重装小兔」使用 **三条相互独立的武装能量**，而非原作按固定顺序永久解锁武装的机制。

| 武装 | 能量增加来源 | 能量消耗方式 |
|---|---|---|
| **激光** | 角色普通攻击 | 重装小兔自动发动激光攻击，消耗激光能量 |
| **导弹** | 角色闪避 | 重装小兔自动发射导弹，消耗导弹能量 |
| **浮游炮** | 角色造成寒冷伤害 | 重装小兔自动以浮游炮攻击，消耗浮游炮能量 |

**行为规则（已确认）：**

1. 三种能量分别积累、分别消耗，互不依赖，没有导弹→激光→浮游炮的先后顺序。
2. 玩家通过对应战斗行为产生能量，重装小兔自主选择可使用的武装攻击敌人并消耗对应能量。
3. **重装小兔不具有不消耗武装能量的基础攻击、免费机枪或其他无条件自动伤害。**
4. 某种能量不足时，该种武装不能发动攻击；全部武装能量不足时，重装小兔停止攻击。
5. 不额外赋予重装小兔自身随时间恢复武装能量的机制。自动攻击不能脱离玩家战斗行为持续白嫖伤害。
6. 三种能量是持续循环使用的战斗资源，**不是**一次充满即永久解锁的开关。

这里说的「解锁武装」是设计过程中的旧称；当前正式机制应写作「武装充能／自动消耗」。

### 2.2 与终极记忆的专属充能联动（已确认）

- **重装小兔消耗武装能量发动的攻击，为专属终极记忆「形态切换」提供额外充能。**
- **重装小兔的攻击不得给其他终极记忆充能**，包括不得借用它们通用的「造成伤害」充能渠道间接获益。
- 角色本人正常造成的伤害，仍按游戏原本的终极记忆充能规则结算；限制对象是重装小兔的攻击事件。
- 额外充能如何按攻击次数、能量消耗或其他口径计算，尚未确定。

### 2.3 尚待设计

- 普攻以发动还是命中获取激光能量；闪避是否要求实际躲避成功；寒冷伤害按命中次数还是伤害量计能量。
- 三条能量槽的上限、单次获取量、单次开火消耗、自动开火节奏、索敌优先级。
- 能量是否在切换形态、房间切换、死亡与复活时保留。
- 重装小兔在延拓形态时的存在和攻击方式；不把延拓形态的自动浮游炮群默认视为身份记忆的武装。
- 角色以外的召唤物、通用记忆、持续伤害引发的寒冷伤害是否参与能量获取，以及如何避免触发循环。

## 3. 专属终极记忆：「形态切换」

### 3.1 核心效果（已确认）

- 作为**终极记忆**，负责极值形态与延拓形态的转换。
- 玩家可以只装备形态切换、不装备「重装小兔」，仍然使用双形态战斗。
- 终极记忆遵循《梦之形》的基础充能框架；装备「重装小兔」时，获得来自重装小兔武装攻击的**专属额外充能**。
- 玩家替换成其他终极记忆时，仍可以独立使用「重装小兔」，但不会把上述额外充能转给替换后的终极记忆。

### 3.2 两项记忆的组合关系（已确认）

| 构筑 | 可以使用的能力 | 效率关系 |
|---|---|---|
| 重装小兔＋形态切换 | 三种充能式协同武装；双形态；专属终极额外充能 | 完整联动 |
| 仅重装小兔 | 三种能量获取与消耗式自动协同攻击 | 不能享受形态切换的联动收益 |
| 仅形态切换 | 使用原版途径为终极记忆充能，并进入完整机甲战斗 | 无重装小兔带来的额外充能 |
| 两者均不装备 | 角色原有基础战斗与其他记忆构筑 | 不使用两项专属机制 |

**设计意图：**两项记忆单独使用时均可发挥完整功能，同时装备时相互提高作战效率；不是一方缺失就让另一方失效。

### 3.3 尚待设计

- 极值形态进入延拓形态的充能阈值、基础冷却参数及专属额外充能数值。
- 延拓形态的持续时间、退出条件、返回极值形态的操作与是否需要再次充能。
- 在延拓形态中终极记忆能否继续充能；切换时是否重置终极能量。
- 普通旅行者记忆及通用记忆在形态间是否保留相同行为，或发生可控变化。

## 4. 双形态基础战斗

### 4.1 极值形态（已确认部分）

- 使用布洛妮娅本体模型。
- 普通攻击、闪避和造成寒冷伤害都可以作为「重装小兔」对应武装的能量来源。
- 极值形态普攻的具体动作、闪避动画及其余主动记忆尚未定稿。
- 未装备身份记忆时，基础角色仍可以正常使用专属终极记忆的形态切换。

### 4.2 延拓形态：完整机甲（已确认）

延拓形态拥有与极值形态独立的基础战斗方式：

| 基础机制 | 已确定表现 |
|---|---|
| **普通攻击** | **变为光束照射** |
| **闪避** | **变为传送，同时释放大量飞弹** |
| **持续作战机制** | **延拓形态持续期间召唤大量浮游炮，自动寻找目标战斗** |

具体约束：

1. 光束是机甲形态的普通攻击，不仅是播放一道附着在原普攻上的光效。其是否长按持续、伤害跳数、攻速换算与命中规则待设计。
2. 机甲闪避以传送取代原动作，并伴随大量飞弹；传送距离、无敌帧、飞弹数量与跟踪规则待设计。
3. **机甲形态自身的浮游炮群由专属终极记忆提供**，在延拓形态持续期间自动作战，不要求装备「重装小兔」。
4. **机甲浮游炮群与身份记忆的浮游炮是两套来源不同的机制。**「重装小兔无免费攻击」限制的是身份记忆的三武装，不应误套到专属终极记忆本身的机甲火力上。
5. 机甲浮游炮群是否消耗其他资源、其攻击频率与伤害倍率、机甲退出时如何回收，均未确定；这里只确认形态持续期间自动战斗。

## 5. 实现与平衡的验证项

下列均属于**待技术验证**，不等于已确认能够直接调用某个 API：

- **形态切换：**同一角色对象能否安全更换模型、攻击、闪避、受击相关组件，并可恢复至极值形态。
- **光束普攻：**持续光束的目标追踪、命中结算、普攻效果触发及攻速／暴击／精粹兼容。
- **闪避传送：**导航合法落点、位移安全、无敌时间与飞弹追踪；多人联机的一致性。
- **大量浮游炮：**自动索敌与伤害调度、性能上限、客户端显示与联机同步。
- **能量系统：**角色行为触发归属、寒冷伤害识别、三条武装能量的同步及资源扣除时机。
- **终极记忆专属充能：**使重装小兔攻击对「形态切换」额外充能，但彻底排除对其他终极记忆的直接与间接充能。
- **伤害归属与循环：**浮游炮／飞弹可能产生寒冷伤害时，是否会形成「自动攻击→能量增长→继续自动攻击」的异常循环。
- **联机生命周期：**换房间、死亡复活、晚加入、断线重连、切换形态、替换记忆后的状态一致性。
- **模型与动画：**首版直接替换两套独立 3D 模型；真实组合变形动画不在本版范围。

技术接口与开发路线应在原型验证后另行记录，避免与角色规则混写。
